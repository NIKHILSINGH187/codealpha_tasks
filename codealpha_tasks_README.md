## Tasks Completed

| # | Task | Folder | Description |
|---|------|--------|-------------|
| 1 | Basic Network Sniffer | [`Task1_NetworkSniffer`](./Task1_NetworkSniffer) | A Python + Scapy tool that captures live network traffic and displays source/destination IPs, protocols, ports, and payload previews. |
| 2 | Phishing Awareness Training | [`Task2_PhishingAwareness`](./Task2_PhishingAwareness) | An interactive HTML training module covering phishing recognition, social engineering tactics, fake website detection, best practices, and a 5-question quiz. |
