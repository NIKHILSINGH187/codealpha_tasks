# CodeAlpha_PhishingAwarenessTraining

An interactive phishing awareness training module built as part of the **CodeAlpha Cyber Security Internship** (Task 2).

## What this project does

A self-contained, interactive HTML training module that teaches how to recognize and avoid phishing attacks — built to be opened directly in a browser, with no installation or server required.

## File in this folder

| File | Description |
|------|--------------|
| `phishing_awareness_training.html` | The complete training module. Open it in any browser to view. |

## What the module covers

1. **What phishing is** — email phishing, spear phishing, whaling, smishing/vishing, clone phishing, angler phishing
2. **Anatomy of a phishing email** — an annotated example highlighting 5 common red flags (spoofed sender domain, generic greeting, urgency, mismatched links, poor grammar)
3. **The psychology behind it** — the social engineering tactics attackers rely on: urgency, authority, fear, curiosity, trust, and reciprocity
4. **Spotting a fake website** — domain spoofing, the padlock myth, and redirect tricks
5. **Best practices checklist** — 7 concrete habits to avoid falling victim
6. **Real-world attack patterns** — Business Email Compromise (CEO fraud), credential-harvesting worms, and delivery-scam texts
7. **An interactive 5-question quiz** — click an answer to see instantly whether it's correct, with an explanation, live score tracking, and a reset option

## How to use it

Just download `phishing_awareness_training.html` and open it in any web browser (Chrome, Firefox, Edge, etc.) — no setup needed.
